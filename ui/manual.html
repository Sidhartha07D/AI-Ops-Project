Using Smart Maintenance

Check a reading

Choose machine type L, M or H and enter five sensor values in the displayed units. Choose Routine sample or Inspection sample to try a demonstration, then select Check reading.

The result is a model score for a synthetic equipment record. The inspection threshold helps prioritize human review; the score does not predict when real equipment will fail.

Correct an error

If a value is outside the accepted range, correct it and submit again. If the model is unavailable or a release is in progress, wait and retry. A failed request has no new valid prediction.

Flag a result

Select Flag this result for review after a prediction. The current interface saves a review flag; it does not collect an outcome label or automatically train a new model.

Pipeline status

The separate pipeline page shows stored stage outputs, the last local workflow and a validation console. Run validation checks the source CSV without retraining. The workflow details show actual recorded checks and timings.
